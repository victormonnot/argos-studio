# Documentation screenshots

These screenshots were captured from ARGOS Studio on 2026-10-10 with Chromium
at a 1440 × 1000 desktop viewport and normal browser zoom. They show selected
regions of the interface, leaving out the empty sidebar after scrolling.
No text, measurements or chart data were changed for the images.

| File | View |
| --- | --- |
| [session.png](session.png) | Completed synthetic session, full-window chart and measured reception gap. Capture region: 1118 × 735. |
| [investigation.png](investigation.png) | Saved local investigation of the same session, with the observation, evidence links, hypotheses and limits. Capture region: 1118 × 970. |

The session contains 251 samples over about 14.5 seconds. A requested two-second
pause produced a measured interval of about 2.05 seconds between adjacent
samples. These are mathematical signals generated by Studio, not flight dynamics
or physical sensor measurements. The report is deterministic and uses no AI model.

To reproduce a similar view, follow the [first-session walkthrough](../../README.md#try-a-first-session).
Allow several seconds of measurements before and after the interruption, then
stop the session and open a reception investigation. Exact sample counts and
intervals depend on when the controls are used and on local scheduling.
